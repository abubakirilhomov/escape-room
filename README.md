# ESCAPE ROOM: SECRET LABORATORY

Учебный браузерный проект на **HTML, Tailwind CSS v4 и Vanilla JavaScript** с использованием **Vite** в качестве сборщика. Игрок исследует секретную лабораторию, собирает предметы, решает загадки и пытается выбраться до окончания таймера.

## Цель проекта

Создать законченную небольшую игру, в которой ученики применяют темы курса на практике:

- переменные, типы данных и условия;
- `Math` и строковые методы;
- объекты и массивы;
- `for`, `forEach`;
- DOM и BOM;
- функции и обработчики событий.

ИИ-инструменты (Antigravity или Codex) используются как помощники-разработчики и наставники. Ученик должен понимать и уметь объяснить весь код.

## Быстрый старт

1. Установите зависимости: `npm install`.
2. Запустите dev-сервер: `npm run dev`.
3. Откройте папку проекта в Antigravity или Codex.
4. Перед началом попросите агента прочитать `AGENTS.md` и все документы из `docs/`.
5. Реализуйте этапы по порядку из [`docs/ROADMAP.md`](docs/ROADMAP.md).
